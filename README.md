# EKS Forge App of Apps

[EKS Forge](https://eks-forge.readthedocs.io/latest/) is an open-source platform for building and operating [EKS](https://aws.amazon.com/eks/) clusters.

This repository holds its Kubernetes-side Helm charts and manifests, deployed by ArgoCD through the [App of Apps pattern](https://argo-cd.readthedocs.io/en/latest/operator-manual/cluster-bootstrapping/#app-of-apps-pattern-alternative).

## Documentation

Read the [Applications documentation](https://eks-forge.readthedocs.io/latest/docs/applications/get-started/).
